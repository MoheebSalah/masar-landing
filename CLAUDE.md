## Coding Rules 

- The strucutre of the code must be clean, uses components, and Seperation-of-conecnrs must be applied.
- inside src/app/ the folder of the project must be well organized each folder is for each section.
- Components go in src/app/components.
- Prefer using libraries to do complicated actions, like GSAP, or Framer motion.
- If there are some feature that require libraries to be installed, and they are not installed, then ask me first.
- Do not use content.ts, put the constants (whethere they are numbers or text) hard coded inside the html tag.

## Styling

- Tailwind only.
- Don't use inline styles.
- Use Tailwind css for styling, if a style, feature or an animation are very complicated to implement, and only pure css files will solve it, then you can make css files with a small code in them.
- Keep class names readable.

## When Editing

- Don't change unrelated files.
- Explain major changes before making them.

## Testing

- Run lint after modifications.
- Fix TypeScript errors before finishing.

## Language :
- the language of the website is arabic only, RTL.
